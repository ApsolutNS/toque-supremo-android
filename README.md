# TOQUE SUPREMO

Videojuego para Android desarrollado con **Godot 4** y **GDScript**.

> Estado: en desarrollo temprano (configuración inicial del proyecto).

## Requisitos

- [Godot 4.x](https://godotengine.org/download) (versión estable)
- [Git](https://git-scm.com/) o [GitHub Desktop](https://desktop.github.com/)
- JDK y Android SDK (solo para exportar a Android)

## Cómo abrir el proyecto

1. Clona el repositorio con GitHub Desktop o con Git:
```bash
   git clone https://github.com/<tu-usuario>/<tu-repositorio>.git
```
2. Abre Godot, pulsa **Importar** y selecciona el archivo `project.godot`.
3. Espera a que Godot genere la carpeta `.godot/` (es automática y no se versiona).

## Estructura del proyecto

La estructura de carpetas se irá definiendo por etapas. Todo el contenido del juego vive dentro de la raíz del proyecto Godot.

## Convenciones

- Nombres de archivos y carpetas en `snake_case`.
- Un commit por cambio lógico, con mensajes claros.
- Trabajo por etapas; cada etapa cierra con un commit.

## Seguridad

Este repositorio **no** debe contener claves de firma, keystores, tokens ni contraseñas.
Los archivos sensibles están excluidos en `.gitignore` y deben guardarse fuera de la carpeta del repositorio.
